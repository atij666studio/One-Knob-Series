AtiNAMatiC Pitch

Drop tuning (0 to -7 semitones), stereo detune (0-25 cents) and an
octave-down voice, with a pitch-synchronous shifter that keeps single notes
clean. Full chords at big shifts warble a little, as with any real-time
shifter.

Signal chain position: before the amp for Drop / Octave, after the amp for
Detune.

Guitar -> [AtiNAMatiC-Pitch] -> Amp Sim -> Cab/IR -> DAW

PITCH   semitones (Drop) / cents (Detune) / octave level (Octave)
MODE    Drop / Detune / Octave
MIX     wet/dry or added-voice level
OUTPUT  final trim

See docs/AtiNAMatiC-Pitch-Manual.md for details.
