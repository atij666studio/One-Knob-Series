AtiNAMatiC Slow

Automatic volume swells: every new pick is hidden and the note fades in, like
a slow-gear pedal. Swell time 50 ms to 2 s; Swell, Pad or Reverse curves.

Signal chain position: before the amp (classic) or after it (smoother).

Guitar -> [AtiNAMatiC-Slow] -> Amp Sim -> Cab/IR -> Reverb -> DAW

SWELL TIME  how long each note takes to fade in
CURVE       Swell / Pad / Reverse
MIX         let some of the pick attack through
OUTPUT      final trim

See docs/AtiNAMatiC-Slow-Manual.md for details.
