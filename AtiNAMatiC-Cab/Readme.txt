AtiNAMatiC Cab

A one-knob speaker cabinet for amp captures that have no cab. The knob moves
the microphone from the dust cap (bright) to the cone edge (dark); the mode
picks the cabinet (1x12 / 2x12 / 4x12). Level is matched automatically.

Signal chain position: after an amp sim that has no cabinet.

Guitar -> Amp Sim (no cab) -> [AtiNAMatiC-Cab] -> DAW

MIC POSITION  cap (bright) -> edge (dark)
CABINET       1x12 / 2x12 / 4x12
MIX           blend with the raw amp
OUTPUT        final trim

See docs/AtiNAMatiC-Cab-Manual.md for details.
