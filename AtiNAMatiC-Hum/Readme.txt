AtiNAMatiC Hum

Removes mains hum (50/60 Hz) and single-coil buzz (its harmonics) with very
narrow notches, while you play. Auto detects 50 or 60 Hz.

Signal chain position: first, before the gate and the amp.

Guitar -> [AtiNAMatiC-Hum] -> Gate -> Amp Sim -> DAW

HUM REMOVAL  depth and number of harmonics (0 = off)
MAINS        Auto / 50 Hz / 60 Hz
OUTPUT       final trim

See docs/AtiNAMatiC-Hum-Manual.md for details.
